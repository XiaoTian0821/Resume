# 简历 HTML 生成说明

## 已创建文件
- `resume.html` - A4 尺寸打印优化简历

## 使用方法

### 方法一：浏览器打印导出 PDF
1. 在浏览器中打开 `resume.html`
2. 按 `Ctrl+P`（Mac: `⌘+P`）
3. 选择"另存为 PDF"
4. 保存即可

### 方法二：直接修改后使用
编辑 `resume.html`，填入以下信息：

#### 必填项
- 姓名
- 联系方式（邮箱、电话、地址）
- 个人网站 URL
- 教育信息（学校、专业、时间、GPA）
- 技能标签
- 项目经验
- 证书与资格

#### 可选项
- 职业目标摘要
- 工作经验
- 语言能力
- 参考人信息

## 技术细节

- 精确 A4 尺寸：210mm × 297mm
- 打印优化 CSS：`@page`、`@media print`
- 无动画、无多余装饰
- 单色配色，适合黑白打印
- 紧凑排版，充分利用 A4 空间

## 设计特点

- 清晰的章节分隔（深色标题条）
- 技能标签化展示
- 两栏布局，信息密度高
- 打印时自动隐藏提示条
